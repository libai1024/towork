ToWork

iPhone、iPad 与 Mac 支持

开始使用

从侧栏进入待办、日程或数据。要与 AI 对话，在「设置 → 模型与额度」添加你的模型账户，然后回到对话页输入问题。

连接与额度

在模型账户编辑页检查连接。核对密钥、模型名称和服务地址。订阅额度与 API 余额由所选的服务商管理。

语音输入

按住录音，松手发送，滑到编辑区域可先修改转写文字。首次使用时请允许麦克风权限。权限关闭后，可前往系统设置重新开启。

版本与更新

App Store 用户在商店获取更新，测试人员通过 TestFlight 获取测试构建。App 版本可在「设置 → 关于」查看。
