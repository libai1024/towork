# 模型品牌图标

更新于 2026-11-17。图标用于标识对应模型或服务商，按原始比例渲染。供应商图标统一黑白处理，SVG 使用浅色主题黑色、深色主题白色，智谱 PNG 使用灰度滤镜。自定义兼容连接使用 Lucide 插头图标。

| 素材 | 来源 |
| --- | --- |
| `kimi.svg` | LobeHub 的 Kimi 单色标识，当前运行界面使用。[原文件](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/kimi.svg) |
| `kimi.png`（历史素材） | Kimi 官网声明的 PWA 图标，192×192。[原文件](https://www.kimi.com/pwa-192.png)、[品牌指南](https://www.kimi.com/resources/kimi-brand) |
| `zhipu.png` | 智谱开放平台官网声明的图标。[原文件](https://open.bigmodel.cn/static/images/favicon.png)、[官网](https://open.bigmodel.cn/) |
| `deepseek-color.svg` | LobeHub 图标库的 DeepSeek 彩色标识。[原文件](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/deepseek-color.svg)、[DeepSeek 官网](https://www.deepseek.com/) |
| `claude-color.svg` | LobeHub 图标库的 Claude 彩色标识。[原文件](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/claude-color.svg) |
| `gemini-color.svg` | LobeHub 图标库的 Gemini 彩色标识。[原文件](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/gemini-color.svg) |
| `openai.svg` | LobeHub 图标库的 OpenAI 单色标识。[原文件](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg) |
