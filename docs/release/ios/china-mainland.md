# 中国大陆上架准备

ToWork 待办与日程由 Silicon Nexus LLC 提交。App Store Connect 记录为 6836602322，套装标识为 `com.towork.towork`。美国为首发地区。以下材料用于之后申请中国大陆正式分发。

## 产品说明草稿

ToWork 是本地工作管理工具，包含待办、日程、表格、报告和记忆。AI 对话和文本生成按需启用，使用用户配置的模型服务。服务商接收请求所需的内容，ToWork 本地保存业务记录。iPhone 和 iPad 语音输入在设备上转写。详见[隐私政策](https://zhaozhaoyue.top/towork/privacy.html)。

| 待核实的资料 | 对照内容 |
| --- | --- |
| App 备案 | 核对工信部备案主体、App 名称、有效备案号及其与商店主体的关系。官网域名备案和模型服务商备案不能替代 App 本身的备案。 |
| AIGC 服务声明 | 依据 Apple 后台问题申报实际文本生成能力、接入服务商和适用的备案或登记证明。自定义 API 地址和跨地区服务均须纳入实际分发配置的核对。 |
| 安全评估 | 按 Apple 对本 App 显示的要求提交全国互联网安全管理服务平台通过的记录和相关报告。材料须来自实际运营主体。 |
| 开放销售 | 核实材料与上架版本后，在「App 合规」填写，再将中国大陆加入「价格与销售范围」。 |
